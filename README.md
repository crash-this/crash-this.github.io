# crash-this.github.io

The page of CRASH, the Cultural Heritage Advanced Search Hackathon: Graz, 30 November and
1 December 2026. Online at https://crash-this.github.io/.

One page, no build step: `index.html`, `style.css`, `fx.js`, the favicon, the share image
and the fonts. To view it locally, serve the folder and open http://localhost:8765:

```
python3 -m http.server 8765
```

The effects (scanlines, glow, the flicker of the wordmark) can be switched off on the
page; without JavaScript they stay off and the page reads the same.

The front-end style was coded with Claude Opus 5.

Fonts: Redaction (MCKL Inc.) and Departure Mono (Helena Zhang), both under the SIL Open
Font License 1.1; the licence texts are in `fonts/`.
